#**********************************************************************************************************
# CLUMPY -g8 galaxy ENSEMBLE manifest
# --------------------------------------------------------------------------------------------------------
# One row = one Milky-Way-type galaxy realization to be drawn with `clumpy -g8`.
# The batch driver clumpy_g8_ensemble.sbatch reads this file and runs the row whose
# (1-based) data-line index equals SLURM_ARRAY_TASK_ID+1, passing each column as a
# --gXXX override on top of clumpy_config/clumpy_params_g8.txt. This reproduces the
# publicly released *.drawn catalogues (/data/data/CLUMPY/data/*drawn) and lets you
# grow a statistically significant set of galaxies differing in:
#   - realization (SEED)          -> a fresh random draw of the whole clump population
#   - DM particle mass (MDM_GEV)  -> paper uses 100 and 500 GeV, chi chi -> b bbar
#   - clump census   (NCLUMPS)    -> gMW_SUBS_N_INM1M2, # massive clumps in [M1,M2]
#   - clump mass floor (MMIN)     -> gDM_SUBS_MMIN  (m07 = 1e-7, m08 = 1e-8 Msol ...)
#   - clump mass ceiling (MMAXFRAC)-> gDM_SUBS_MMAXFRAC (0.01, 0.2 ... of host mass)
#   - map orientation (PSI,THETA) -> l.o.s. map centre; appears as LOS<PSI>_<THETA>
#   - injected galaxy (GALLIST)   -> which external MW-type galaxy (inclination) to add
#   - resolution (NSIDE)          -> gSIM_HEALPIX_NSIDE (2048 in the paper)
#
# GALLIST column (selects the external list halo added by -g8 via gLIST_HALOES):
#   none     -> --gLIST_HALOES=-1  : NO external object; pure MW Galactic clump draw.
#                                    Use this to reproduce the released clump catalogues.
#   default  -> (no override)      : use the param-file default clumpy_config/list_haloes.txt
#                                    (MW + the DSPH/CLUSTER samples + ALL 6 MWtype galaxies).
#   <path>   -> --gLIST_HALOES=<path> : one specific per-inclination file, e.g.
#                                    clumpy_config/list_MWtype_i45.txt  (see list_MWtype_*.txt).
#              Available inclinations: i00 (face-on), i30, i45, i60, i90 (edge-on),
#              i45pa60 (i=45 deg with position angle 60 deg).
#
# Notes
#  - Lines starting with # and blank lines are ignored.
#  - Columns are whitespace-separated; keep the column count fixed (11 columns).
#  - Use NCLUMPS = -1 / MMIN = -1 / MMAXFRAC = -1 to keep the param-file default.
#  - CLUMPY builds the output *.drawn name itself from these values, so matching a
#    row to a released file is a direct look-up of seed/masses/LOS/nside.
#  - The number of --array tasks must cover the data-line count (see driver header).
#
# Column key:
#  ID     : short human tag for the realization / output subfolder
#  SEED   : gSIM_SEED               (integer; 0 = clock-seeded, NOT reproducible)
#  MDM_GEV: gPP_DM_MASS_GEV         [GeV]
#  NCLUMPS: gMW_SUBS_N_INM1M2       (-1 = keep default 150)
#  MMIN   : gDM_SUBS_MMIN           [Msol] (-1 = keep default 1e-6)
#  MMAXFR : gDM_SUBS_MMAXFRAC       [-]    (-1 = keep default 0.01)
#  PSI    : gSIM_PSI_OBS_DEG        [deg]  (l.o.s. / map-centre longitude)
#  THETA  : gSIM_THETA_OBS_DEG      [deg]  (l.o.s. / map-centre latitude)
#  NSIDE  : gSIM_HEALPIX_NSIDE      [-]
#  GALLIST: external galaxy list    (none | default | clumpy_config/list_MWtype_*.txt)
#  LABEL  : free note (no spaces)
#
#*******************************************************************************************************************#
